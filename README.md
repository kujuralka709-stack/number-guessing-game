# 🎯 Number Guessing Game

## 📌 About the Project
The Number Guessing Game is a simple and interactive web application developed using HTML, CSS, and JavaScript.

The computer generates a random number between 1 and 100, and the player tries to guess it. The game provides hints to help the player guess the correct number.

## 🚀 Features
- Generates a random number between 1 and 100.
- Provides higher and lower hints.
- Counts the number of attempts.
- Validates user input.
- Displays a success message when the correct number is guessed.
- Includes a Play Again button to restart the game.
- Simple and user-friendly interface.
- Responsive design for different screen sizes.

## 🛠️ Technologies Used
- **HTML5** — Creates the structure of the webpage.
- **CSS3** — Styles the webpage.
- **JavaScript** — Implements the game logic and functionality.

## ▶️ How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Make sure all three source files are in the same folder.
4. Open `index.html`.
5. Right-click and select **Open with Live Server**.

You can also open `index.html` directly in your web browser.

## 🎮 How to Play

1. Enter a number between 1 and 100.
2. Click the **Check Guess** button.
3. Read the hint:
   - **Too low:** Guess a higher number.
   - **Too high:** Guess a lower number.
   - **Correct:** You win!
4. Check your total attempts.
5. Click **Play Again** to start a new game.
